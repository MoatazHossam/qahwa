# Map pictures

The pictures for the map questions in «الجغرافيا»: `map-<code>.svg` shows a country highlighted in its region, and
`shape-<code>.svg` shows a country's outline alone (its answer picture is the matching `map-<code>.svg`). `<code>` is the
country's two-letter ISO code.

Made from [Natural Earth](https://www.naturalearthdata.com/) (public domain) through the `world-atlas` package by
`maps/gen.mjs` in the quiz-platform repository. Other land is drawn as one shape with no borders, and there are no
labels, so a picture never gives its answer away.
